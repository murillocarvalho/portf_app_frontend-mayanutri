# Site institucional para nutricionista

Projeto em Node.js com Express para um site de apresentação com páginas de:
- início
- agendamento
- contato
- perguntas frequentes

## Rodar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor:
   ```bash
   npm start
   ```
3. Acesse: http://localhost:3000

## Hospedagem gratuita

Recomendado: Render
- Crie um repositório no GitHub com estes arquivos
- Conecte o repositório ao Render
- Use o comando de inicialização: `node app.js`
- O Render irá usar a variável de porta automaticamente
